# Sistema de Gestão de Impressão 3D

Sistema web para gerenciamento de produção, custos, estoque, produtos e
pedidos para negócios de impressão 3D.

## Estrutura do Projeto

    App-Impressao-3D/

    ├── index.html
    │
    ├── css/
    │   └── style.css
    │
    ├── js/
    │   ├── database.js
    │   ├── utils.js
    │   ├── equipamentos.js
    │   ├── almoxarifado.js
    │   ├── precificacao.js
    │   ├── vitrine.js
    │   ├── pedidos.js
    │   └── app.js
    │
    └── README.md

## Funcionalidades

### Equipamentos

-   Cadastro de impressoras 3D
-   Controle de valor de compra
-   Vida útil
-   Consumo elétrico
-   Cálculo de depreciação

### Almoxarifado

-   Controle de matérias-primas
-   Controle de insumos
-   Estoque

### Precificação

-   Material
-   Energia
-   Depreciação
-   Mão de obra
-   Encargos
-   Complexidade
-   Taxas de venda
-   Margem de lucro

### Vitrine

-   Cadastro de produtos
-   Controle de estoque
-   Catálogo visual

### Pedidos

-   Controle de vendas
-   Status de produção
-   Controle de faturamento

## Instalação

1.  Baixe todos os arquivos.
2.  Mantenha a estrutura de pastas.
3.  Abra o arquivo:

```{=html}
<!-- -->
```
    index.html

## Publicação no GitHub Pages

1.  Crie um repositório no GitHub.
2.  Envie todos os arquivos.
3.  Acesse:

Settings \> Pages

4.  Ative o GitHub Pages.
